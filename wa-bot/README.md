# بوت واتساب مجاني لتنبيهات مِحكام

بوت يتصل بواتساب عبر **مسح QR** (مثل واتساب ويب) ويرسل التنبيهات. **مجاني بالكامل** — لا اشتراك ولا API مدفوع. يعتمد مكتبة [Baileys](https://github.com/WhiskeySockets/Baileys) مفتوحة المصدر.

> ⚠️ **مهم:** استخدم **رقم واتساب مخصّصاً للتنبيهات** (ليس رقمك الشخصي)، وابقِ الاستخدام على التنبيهات فقط (لا رسائل جماعية / تسويق) لتفادي إيقاف الرقم من واتساب.

---

## أين تشغّله؟

البوت يحتاج **تشغيلاً دائماً** (24/7). الاستضافة المشتركة (cPanel) لا تدعم Node.js الدائم، فاختر واحداً:

| الخيار | التكلفة | ملاحظات |
|---|---|---|
| **Oracle Cloud — Always Free** | مجاني للأبد | جهاز افتراضي VM حقيقي (ARM). الأفضل. |
| Raspberry Pi / حاسب قديم في المكتب | مجاني (جهاز موجود) | اتركه يعمل |
| هاتف Android قديم عبر Termux | مجاني | راجع قسم Termux أدناه |
| أي VPS رخيص (Hetzner/Contabo…) | ~1-4$ شهرياً | أسهل إعداد |

## الإعداد على Ubuntu (VPS / Oracle / Pi)

```bash
# 1) ثبّت Node.js 20
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# 2) انسخ مجلد wa-bot إلى الخادم ثم:
cd wa-bot
npm install

# 3) شغّله مع مفتاح سري طويل
WA_SECRET="ضع-هنا-مفتاحاً-عشوائياً-طويلاً" PORT=3000 npm start
```

سترى رمز QR في الطرفية — امسحه من: **واتساب ← الإعدادات ← الأجهزة المرتبطة ← ربط جهاز**.
(أو افتح `http://عنوان-الخادم:3000/qr` في المتصفح.)

### تشغيله دائماً (PM2)

```bash
sudo npm install -g pm2
WA_SECRET="مفتاحك" PORT=3000 pm2 start server.js --name mehkam-wa
pm2 save
pm2 startup    # نفّذ السطر الذي يظهر
```

## Termux على هاتف Android (بدون خادم)

```bash
pkg update && pkg install nodejs
# انسخ مجلد wa-bot إلى ~/wa-bot
cd wa-bot && npm install
WA_SECRET="مفتاحك" npm start
```
امسح الـ QR من هاتف آخر. اترك Termux يعمل (عطّل تحسين البطارية له).

---

## ربطه بمنصة مِحكام

لوحة الإدارة ← **إعدادات المنصة ← تنبيهات واتساب**:

- المزوّد: **بوت خاص (Self-hosted)**
- الرابط: `http://عنوان-الخادم:3000` (أو دومين/HTTPS إن وفّرته)
- المفتاح السري: نفس قيمة `WA_SECRET`

ثم زر «اختبار». وكل مستخدم يضيف رقم واتسابه من ملفه الشخصي.

---

## نقاط الوصول (Endpoints)

| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/` | `{ ok, connected }` |
| GET | `/qr` | صفحة رمز الربط |
| POST | `/send` | `{ secret, phone, text }` → `{ ok }` |

## إعادة الربط

لو انفصل نهائياً (`loggedOut`): احذف مجلد `auth/` وأعد تشغيل البوت وامسح QR جديد.
